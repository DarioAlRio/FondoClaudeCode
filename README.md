# FondoClaudeCode

Extensión de Chrome que sustituye la Nueva pestaña por un fondo animado de letras, inspirado en la pantalla de inicio de Claude Code.

- Letras tenues sobre fondo oscuro, con "humo" que se desplaza en diagonal (dirección al azar en cada pestaña).
- Brillos irregulares que aparecen y desaparecen.
- El ratón aparta el humo a su paso.
- Buscador central y enlace a Gmail.

## Instalación

1. Descarga o clona este repositorio.
2. Abre `chrome://extensions` y activa el **Modo desarrollador**.
3. Pulsa **Cargar descomprimida** y elige la carpeta del proyecto.
4. Abre una pestaña nueva.
